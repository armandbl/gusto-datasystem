# Example velocity configuration file for measure_offsets_gaussian_fitting.py
# Format (tab-separated or whitespace):
#   velocity_kms  [lon_deg  lat_deg  [weight]]
#
# Lines starting with # are ignored. 
# velocity_kms is REQUIRED.
# lon_deg, lat_deg (Galactic coordinates) are OPTIONAL. If provided, script searches for peak in that region.
# weight is OPTIONAL. If provided, used to weight this velocity in final aggregation.
#
# Examples:
#   -20                              # Just velocity, auto-detect peak globally
#   -38  -22.5  -23.2               # Velocity with Galactic center hint (search nearby)
#   -70  -22.5  -23.2  2.0          # Velocity with hint and explicit weight (higher weight = more important)
